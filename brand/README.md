# CassandraGargoyle brand

The CassandraGargoyle mark: a **C** made of a network of nodes around a **G** whose bar
ends in a node. The green node of the network stands for a verified source. The mark
says what the projects do: they trace information back to where it comes from.

![CassandraGargoyle mark](png/mark-dark-256.png)

## Files

| File | Content |
| ---- | ------- |
| `mark.py` | generator of the mark (Python 3.11+, standard library only) |
| `mark-dark.svg` | the mark on the dark background, generated by `mark.py` |
| `png/mark-dark-<size>.png` | rendered PNG files: 16, 32, 64, 128, 256, 512 and 1024 px |

Do not edit the SVG by hand. Change `mark.py` and generate the files again.

## Colors

| Name | Value | Use |
| ---- | ----- | --- |
| Green | `#76B900` | the G and the verified node |
| Graphite | `#1A1A1A` | background |
| Light | `#F2F2F2` | network nodes and edges |

## Use in projects

- Project icons follow the same style: rounded bars and nodes in these three colors,
  with a motif that shows what the project does.
- Keep the padding around the mark; do not crop it, stretch it, or add effects.
- The mark is legible from 32 px. At 16 px the network merges; a simplified favicon is
  still to be designed.

## Generate

```bash
python3 brand/mark.py dark > brand/mark-dark.svg
for s in 1024 512 256 128 64 32 16; do
  magick -background none brand/mark-dark.svg -depth 8 -resize ${s}x${s} brand/png/mark-dark-$s.png
done
```
